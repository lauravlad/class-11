# Class 11

Predicate logic practice app for PHIL 270 Symbolic Logic. Built in the style of the Therefore logic practice app.

## What's inside

- **Candy Challenge**: a 10-question round mixed from every part. Students who get 8 or more right (over 75%) see a celebration screen with their name and the date to show the teacher for candy.
- **Part 1, Names, predicates, and quantity words**: name the expression, count predicate places
- **Part 2, Reading formulas**: type, main operator, free variables, sentence or not; substitution instances
- **Part 3, All, no, and some**: symbolize A-, E-, I-, and O-sentences, including "only" and "all and only" (any equivalent formula is accepted)
- Quick-check questions for each part and a mixed review

Exercises are generated fresh each time. Progress is saved only in each student's own browser.

## Use

It is a single self-contained file. Open `index.html` in any browser.
